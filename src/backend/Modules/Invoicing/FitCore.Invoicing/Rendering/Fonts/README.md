# Tipografías del RIDE

`DejaVuSansCondensed.ttf` y `DejaVuSansCondensed-Bold.ttf`, versión 2.37 (paquete npm `dejavu-fonts-ttf`), con licencia libre (Bitstream Vera / dominio público para los cambios de DejaVu; ver `LICENSE-DejaVu.txt`), que permite incluirlas y redistribuirlas. Se incrustan en el ensamblado porque la imagen de Docker del Worker y de la API no trae fuentes del sistema, y el PDF debe verse igual en cualquier servidor. Cubren los acentos y la «ñ» del español.
